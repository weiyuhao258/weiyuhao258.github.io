- RoboMaster 比赛项目与演示视频
- 实习经历、科研经历与个人项目快捷导航

## 本地预览

这是一个无构建依赖的静态站点。在项目目录启动任意静态文件服务器即可，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## GitHub Pages

发布地址：<https://weiyuhao258.github.io/>，对应仓库 `weiyuhao258/weiyuhao258.github.io`。

项目已包含 `.github/workflows/deploy-pages.yml`。推送到 `main` 分支后，在仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**，后续提交会自动部署。

部署脚本只收集页面实际引用的资源。原始作品集、可编辑 PPT、论文源文件和临时文件不随站点发布。

站点中的图片与视频均来自个人作品集原始素材；未使用 AI 生成图片。
